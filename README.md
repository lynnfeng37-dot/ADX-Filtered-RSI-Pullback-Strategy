# ADX-Filtered-RSI-Pullback-Strategy
本程序基于豆粕期货前复权主力连续合约数据，构建并回测了一套 RSI + ADX 组合技术指标交易策略。
程序完整覆盖了 数据读取 → 技术指标计算 → 交易信号生成 → 策略回测 → 风险评估 → 结果可视化 的量化研究标准流程，用于评估该策略在历史数据上的收益与风险特征。
程序结构与逻辑说明
## 一、数据读取与预处理模块

程序首先从本地读取已经处理好的 前复权连续合约数据文件，将交易日期转换为时间索引，并剔除价格字段缺失的无效数据，确保后续技术指标计算与回测过程的稳定性和准确性。

该步骤的目的是构建一个 干净、时间序列连续、可直接用于量化分析的数据基础。

## 二、技术指标计算模块（ADX + RSI）

在数据清洗完成后，程序使用 TA-Lib 技术分析库 计算两类核心技术指标：

ADX（Average Directional Index）
用于衡量市场是否存在显著趋势及趋势强度；

RSI（Relative Strength Index）
用于判断价格是否处于短期超买或超卖状态。

通过同时引入趋势类指标与震荡类指标，策略能够在一定程度上避免在无趋势行情中频繁交易。

## 三、交易信号生成模块

在指标计算完成后，程序设定了一组相对宽松的交易参数：

当 ADX 高于阈值时，认为市场存在趋势；

当 RSI 较低时，视为趋势中的短期回调，产生多头信号；

当 RSI 较高时，视为趋势中的短期反弹，产生空头信号。

交易信号在生成后 延迟一个交易日执行，以避免未来函数问题，确保回测结果符合真实交易逻辑。

## 四、回测核心与交易成本建模

在回测模块中，程序引入了较为完整的实盘近似设定，包括：

初始资金规模；

手续费率；

固定滑点假设；

基于仓位变化计算的换手率。

策略每日收益由 持仓方向 × 标的涨跌幅 − 交易成本 构成，并据此计算策略净值曲线，模拟资金随时间的变化过程。

## 五、风险与绩效评估模块

在回测完成后，程序进一步计算多项关键绩效指标，包括：

总收益率：衡量策略整体盈利能力；

最大回撤：反映策略在极端情况下的风险暴露；

夏普比率（年化）：衡量单位风险下的超额收益；

交易次数估计：用于评估策略交易频率与成本敏感度。

这些指标共同构成对策略 收益—风险特征 的综合评价。

## 六、结果保存与复现支持

程序将回测过程中产生的关键数据（如信号、仓位、收益、净值和回撤）保存为 CSV 文件，便于后续复盘、参数调优或二次分析，增强研究的可复现性。

## 七、专业级可视化展示

最后，程序生成一份包含三部分内容的可视化报告：

账户净值曲线：直观展示策略长期表现；

价格与交易信号图：标注多空开仓点，帮助理解策略行为；

水下回撤图（Underwater Plot）：展示策略在不同阶段的回撤深度与持续时间。

该可视化结构符合量化研究和机构投研中常见的策略展示规范。
